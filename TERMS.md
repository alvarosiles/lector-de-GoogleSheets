## 2. Descripción del servicio

Esta aplicación es una herramienta para consultar y editar una hoja de Google Sheets a través de una página web y de una API desplegada en Google Apps Script. No es un servicio administrado: cada instalación la despliega y opera su propietario, con su propia cuenta de Google.

## 3. Uso aceptable

Quien use la aplicación se compromete a:

- acceder solo a hojas para las que tenga autorización;
- no compartir el token con personas no autorizadas;
- no usar la aplicación para almacenar o distribuir contenido ilícito, ni datos de terceros sin base legal;
- no intentar eludir el control de acceso, adivinar tokens ni sobrecargar el servicio de forma intencionada.

## 4. Responsabilidad sobre los datos

- Los datos se almacenan en la hoja de Google Sheets del propietario de cada instalación, que es el único responsable de su contenido, de las copias de seguridad y del cumplimiento normativo.
- Los cambios guardados se escriben directamente en la hoja. Se recomienda usar el historial de versiones de Google Sheets para recuperar información si hace falta.

## 5. Servicios de terceros
